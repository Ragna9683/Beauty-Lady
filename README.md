# Gabinet Kosmetologii — Projekt Komercyjny

Koncepcja nowoczesnej strony internetowej dla gabinetu kosmetologicznego. Projekt został zaprojektowany z naciskiem na najwyższe standardy UI/UX, konwersję oraz lokalne SEO.

## 🚀 O projekcie
Strona łączy w sobie kliniczną elegancję, płynne animacje oraz pełną responsywność na wszystkich urządzeniach (Mobile-First).

### Główne funkcjonalności:
* **Interaktywny kalkulator / Vouchery:** Narzędzie do doboru pakietów zabiegowych z podglądem ceny.
* **Animowane tło (Canvas):** Płynne, nienachalne linie w firmowych barwach, dodające dynamiki interfejsu.
* **System rezerwacji:** Bezpośrednia integracja z zewnętrznym systemem rezerwacji online.
* **Rozbudowane FAQ & Opinie:** Sekcje budujące zaufanie i odpowiadające na najczęstsze pytania klientek.
* **Wysuwany Drawer (Formularz kontaktowy):** Nowoczesna, bezpieczna forma zapytania z walidacją i zabezpieczeniem antyspamowym (Honeypot).

## 🛠️ Stack technologiczny
* **HTML5** (Semantyczna struktura, mikrodane LocalBusiness Schema.json)
* **CSS3** (Custom Properties, Flexbox, Grid, Responsive Design)
* **JavaScript (ES6+)** (Canvas API, interaktywny kalkulator, akordeon FAQ, Lightbox, Slide-out Drawer)
